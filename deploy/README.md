# Развёртывание сайта и CMS

Готовая схема рассчитана на Ubuntu, Nginx и Node.js 22 или новее.

## Что хранится на сервере

- `/opt/gradstroyaudit/data/cms.sqlite` — тексты, статьи, кейсы и пользователи;
- `/opt/gradstroyaudit/media/uploads` — загруженные изображения;
- `/opt/gradstroyaudit/_site` — опубликованный сайт;
- `/opt/gradstroyaudit/backups` — ежедневные резервные копии.
- `/opt/gradstroyaudit/data/cms.sqlite`, таблица `leads` — все заявки с форм.

Эти каталоги не отправляются в GitHub.

## Домены

- `example.ru` и `www.example.ru` — публичный сайт;
- `cms.example.ru` — вход в админ-панель.

Перед установкой необходимо заменить `example.ru` в `nginx.conf.example` на реальный домен.

## Переменные

Скопировать `.env.example` в `.env`, задать реальный домен, электронную почту первого администратора, длинный пароль и случайный секрет сессий.

## Службы

- `gradstroyaudit.service` постоянно запускает сайт и админку;
- `gradstroyaudit-backup.timer` ежедневно создаёт резервную копию и хранит последние 14 копий.

После подключения к VPS установка выполняется один раз. Далее заказчик пользуется только адресом `cms.example.ru`.

## Автономная почта

Скрипт `setup-mail.sh` устанавливает на VPS исходящую почту Postfix и подпись DKIM. Формы не обращаются к сторонним сервисам: заявка сначала сохраняется в CMS, затем локальный почтовый сервер ставит уведомление в очередь.

После запуска скрипт покажет записи SPF, DKIM и DMARC, которые нужно добавить в DNS. У провайдера VPS также нужно задать обратную PTR-запись для IP сервера.

## Telegram для заявок

После обновления приложения подключите созданного в BotFather бота одной командой:

```bash
cd /opt/gradstroyaudit
bash deploy/setup-telegram.sh
```

Скрипт скрыто запросит токен, проверит его через Telegram и сохранит только в
`/opt/gradstroyaudit/.env`. Токен не появляется в CMS и не попадает в Git.

Затем:

1. добавьте бота в нужную Telegram-группу;
2. если группа не находится автоматически, отправьте в ней команду `/start`;
3. откройте CMS → «Общие данные» → «Telegram-группа»;
4. нажмите «Найти группу», «Проверить» и «Сохранить Telegram».
